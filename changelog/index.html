v1.5.3 · 2026-08-11

What's in this release

The app now writes desktop.log next to its database, so if it fails to start before the window appears it records why instead of closing silently.

Release builds switched to Wails' production configuration. Earlier downloads were development builds and shipped developer tooling that end users never need; the Windows binary is about 3 MB smaller as a result.

Built with Go 1.26.5.

Windows: the SmartScreen warning

These binaries are not code-signed. Windows attaches a "downloaded from the internet" mark to the file and SmartScreen warns before running anything it has no reputation for. The application is not modified in any way — this is what Windows shows for any unsigned download.

To run it, click More info → Run anyway.

If nothing happens at all when you double-click, you are most likely signed in as the built-in Administrator account. Windows cannot display the SmartScreen dialog for that account and refuses the launch without showing anything. Clear the mark and it will start:

Unblock-File -Path .\ShadowSecurityScanner-windows-amd64.exe

Some antivirus products also flag unsigned security tools heuristically. This scanner contains thousands of CVE identifiers and references to public exploit databases, which is exactly what it needs to do its job and exactly what generic machine-learning detections react to.

macOS

The DMG is signed with a Developer ID and notarized by Apple, so it opens normally with no Gatekeeper warning.

Linux

Mark the file executable before running it:

chmod +x ShadowSecurityScanner-linux-amd64
./ShadowSecurityScanner-linux-amd64

Requires GTK 4 and WebKitGTK 6.0.
